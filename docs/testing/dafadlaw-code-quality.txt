Findings and changes
--------------------
1. PackagedSmoke mixed application startup, phase dispatch and long inline
   acceptance workflows. Its follow-up workflow combined three process phases.
   Extracted named workflows and verification steps; dispatch now describes the
   test phases while helpers contain their commands and assertions. Existing
   acceptance checks remain in place. This addresses SLAP and method length.

2. StudentCardTest duplicated JavaFX initialization and exception-unwrapping code
   already available in JavaFxTestUtil. Reused the shared helpers while retaining
   coverage that checks original failures and reuse of an initialized toolkit.
   This removes duplication and keeps the tests focused on student-card behavior.

3. FollowUpCommandParser combined the argument-count check with a nested negative
   action expression. Separated action parsing into a small switch, gave parsed
   arguments descriptive names and retained the existing usage-error contract.
   The storage round-trip test's boolean is now named requiresFollowUp.

4. The shared persistence layer left mutations in memory after a failed save and
   wrote records for help/exit and other commands that did not change them.
   Introduced a small immutable ModelSnapshot of the roster list and view state.
   LogicManager orchestrates execution, change detection and saving; the model
   restores state on IO errors. The UI restores the original selection/highlight.
   List.copyOf avoids duplicate roster validation on every command. Snapshot
   creation and restoration preserve the existing observable lists used by the UI.

5. Null tag entries in saved data bypassed checked validation with an NPE.
   Added explicit tag-entry validation so the existing protective startup path
   handles this input. Added storage/startup and packaged regressions.

6. JavaFX removed tab separators before parsing commands. A TextFormatter now
   normalizes them to spaces before they can concatenate adjacent field values.
   UI and packaged checks verify the actual address/email values and saved data.
